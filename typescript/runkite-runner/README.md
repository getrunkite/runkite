# runkite-runner (TypeScript)

TypeScript / LangGraph.js runner for the [Runkite](https://github.com/getrunkite/runkite) control plane.

```bash
npm install -g runkite-runner
runkite-runner --config path/to/langgraph.json \
  --grpc-address 127.0.0.1:50051 \
  --http-address http://127.0.0.1:2026
```
