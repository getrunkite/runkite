# AAIF Sandbox proposal materials

These documents prepare Runkite for an application to the Agentic AI Foundation
(AAIF). They do not establish admission, endorsement, a signed contribution
agreement or transfer of any project asset. On a proposal branch, governance
and roadmap changes remain proposed until merged.

- [Sandbox thesis](aaif-sandbox-thesis.md): intended users, working evidence,
  pre-adoption case and graduation goals.
- [Dependency scope](dependency-scope.md): dependency terms, retained notices
  and the review still needed for release artifacts and foundation onboarding.
- [Community roadmap](../../ROADMAP.md): contribution, interoperability and
  independent operation priorities.
- [Governance](../../GOVERNANCE.md) and [maintainers](../../MAINTAINERS.md): the
  founder-maintained starting point and a path to wider responsibility.

## Application and onboarding boundaries

The application uses the public
[AAIF project proposal form](https://github.com/aaif/project-proposals/blob/main/.github/ISSUE_TEMPLATE/project-proposal.yml)
and the current
[lifecycle policy](https://github.com/aaif/technical-committee/blob/main/governance/project-lifecycle-policy.md).
Sandbox is the requested stage. Runkite is not claiming the production adopters
or organizational diversity required for Growth.

The form requires the prospective signatory's country and an express agreement
to transfer project trademarks and accounts if accepted. The project owner must
provide those answers. Preparing documentation or filing an application does
not execute a contribution agreement, adopt a legal charter, transfer accounts,
domains or trademarks, or establish acceptance. The authorized signatory must
review those commitments separately with LF staff.

Admission requires the approvals, executed agreements, asset transfers and
onboarding conditions in the
[proposal process](https://github.com/aaif/technical-committee/blob/main/project_proposal_process.md).
Review those documents with the owner and LF staff at the appropriate stage.

No AAIF logo or membership claim should be added to product pages during
review. If Sandbox admission is completed, update the status with the required
statement that Sandbox status is not an endorsement, and link the public
admission record. Existing security reporting and release support remain as
described in [SECURITY.md](../../SECURITY.md).
