Try it in ~5 minutes

Docker only. This is also the cold-tester path.

Compose

git clone https://github.com/getrunkite/runkite && cd runkite docker compose -f docker-compose.dev.yml up -d --build

When healthy: open Admin at http://localhost:2026/admin/, create a run against the echo agent, then exercise a connector HITL approve/deny if you want the governance path. Full command list stays in quickstart.
