Install (Supported)

Postgres + Redis is the Supported honesty bar. Dev compose is for demos only.

Laptop demo (not Supported)

docker compose -f docker-compose.dev.yml up -d --build

SQLite + in-memory. Fine for echo/HITL. Not the production claim.

Supported profile

  • POSTGRES_DSN + REDIS_URL
  • Client auth enabled; runner tokens per kind
  • TLS on the client-facing edge
cp .env.example .env   # set POSTGRES_PASSWORD and RUNNER_TOKEN
docker compose up -d --build
curl -sf http://localhost:2026/readyz && echo OK

Full-stack compose runs Postgres, Redis, control plane, and a Python runner. Required secrets fail fast if unset — no silent default passwords.

Kubernetes

Helm chart under deploy/helm/runkite. For the Supported profile, install with the overlay at deploy/helm/runkite/values-supported.yaml (optional TLS overlay: values-tls.yaml). 

helm upgrade --install runkite deploy/helm/runkite \
  -f deploy/helm/runkite/values.yaml \
  -f deploy/helm/runkite/values-supported.yaml

Kind smokes prove packaging; multi-CP HA proof today is Compose soak — treat bare cluster installs as Compatible until a named cloud soak exists.
