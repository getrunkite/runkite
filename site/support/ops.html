Ops

Reclaim, kill, and secrets are plane responsibilities — not SSH folklore.

Reclaim & fencing

If a runner dies mid-job, the plane reclaims and bumps a generation. The stale runner’s later write is fenced out so it cannot overwrite the winner.

Kill / cancel

Cancel from Admin or Agent Protocol. Runners see the assignment go non-current; side effects should stop. Break-glass exists for emergency override windows.

Secrets

Provider credentials live with connector config / secret store — minted into run-bound sessions, not copied into every agent env.

Poison pill

Crash-loop jobs stop reclaiming after a hard max_retries ceiling so one cursed graph cannot spin forever.
