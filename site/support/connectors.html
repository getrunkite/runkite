Connectors & HITL

Plane-minted credentials for a run. Workers never hold long-lived provider secrets.

Run-binding

POST /internal/connectors/{name}/session and MCP proxy calls require an in-flight run (X-Runkite-Run-Id + generation). A bare runner token without those headers gets 401 run_binding_required.

From agent code

# Python (inside a graph node)
from runkite_runner.connectors import get_connector_session

async def my_node(state, config):
    sess = await get_connector_session(config, "salesforce")
    ...

HITL

Mark a connector/tool as requiring approval. The run interrupts; Admin (or API) approves or denies; the plane resumes or fails closed. Mandatory HITL rules can force a human gate for a connector class.
