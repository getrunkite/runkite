Limitations

Supported is an honesty bar, not a marketing ceiling.

Supported profile

POSTGRES_DSN + REDIS_URL + auth + runner tokens + TLS.

Known gaps (summary)

  • Agent Protocol MCP sessions are process-local (sticky routing).
  • Authz is route-level (+ optional agent run grants), not per-tool ACLs outside connector policy.
  • Tenancy is flat tenant_id — no org/team UI.
  • Governance durability (audit/grants/pending/kill) is SQL-only; Mongo returns 501 on those Admin routes.
  • No built-in FinOps dashboards.
  • Kubernetes/Helm is Compatible until a named cloud soak exists (Compose proves multi-CP HA today).
