Runkite

Self-hosted Agent Protocol control plane

One Go binary. Framework-agnostic runners. Embedded Admin UI. Postgres + Redis for HA — with honest tiers for everything else.

GitHub Quick start Limitations 
git clone https://github.com/getrunkite/runkite && cd runkite
make build

export RUNKITE_ALLOW_INSECURE_SERVE=1   # local demo only
./runkite dev --config examples/echo_agent/langgraph.json
# open http://127.0.0.1:2026/admin/
