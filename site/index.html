02 App-owned execution Your existing backend

Your app owns the loop.
Runkite decides on a tool call.

Keep execution in your Next, Nuxt or other backend. Ask the decision API before an operation, then execute only after allow.

  1. Your tool
  2. Decision API
  3. Your executor
  • Allow, deny or pending
  • Shared connector policy
  • SQL decision and approval audit

No Runkite thread or run. Run kill switches, break-glass and spend caps do not apply. Pending continuation and execution stay with your app.

Start with the local echo example

Clone the repo, build the plane, then start the Python runner in another terminal.

Installation guide →
# Terminal 1: control plane
git clone https://github.com/getrunkite/runkite
cd runkite && make build
./runkite dev --config examples/echo_agent/langgraph.json

# Terminal 2: runner, from the same checkout
pip install runkite-runner
runkite-runner --config examples/echo_agent/langgraph.json \
  --grpc-address 127.0.0.1:50051 --http-address http://127.0.0.1:2026

The control plane needs Go to build from source; prebuilt binaries and images are also available. The local example needs a separate runner.
